# efinix_soc_board

Linux-capable control card for an AC in/out lab power supply, based on the **Efinix Titanium Ti135N484I3** FPGA. The
FPGA's hardened quad-core RISC-V runs Linux, with 1 GB LPDDR4, Gigabit Ethernet and eMMC. The card plugs into the
power supply baseboard ([ac_psu_kicad](https://github.com/johonkanen/ac_psu_kicad)) in place of the earlier Ti60F225
and Agilex 5 cards.

Status: schematic in progress. See **[STATUS.md](STATUS.md)** for where the work stands and what comes next.
